# Dellas Legal Firm — CMS

A single-page admin dashboard concept for a law firm's internal case management system (CMS). Built as a static front-end mockup — no backend or build step required.

## Features

- **Dashboard** — case status overview, recent cases, users by role, system activity log, upcoming hearings
- **Case Management** — case detail view with timeline, progress tracker, parties involved, categories, and documents
- **User / Lawyer / Client Management** — role-based user lists and profile views
- **Document Management**
- **Court Management** — hearing details and calendar view
- **Task Management**
- **System Logs**
- **Notifications**
- **Settings**

## Tech Stack

- Plain HTML, CSS, and JavaScript — no frameworks, no build tools, no dependencies
- Single self-contained `index.html` file

## Running Locally

Just open `index.html` in your browser — no server or install step needed.

```bash
git clone https://github.com/<your-username>/dellas-legal-cms.git
cd dellas-legal-cms
open index.html   # or double-click the file
```
